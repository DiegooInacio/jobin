# Inter

Fontes locais da família Inter, em WOFF2, nos pesos 400, 500 e 600.
São carregadas por `next/font/local` no layout da aplicação.

- Projeto: <https://github.com/rsms/inter>
- Licença: SIL Open Font License 1.1, incluída em `OFL.txt`.
- Os arquivos foram copiados sem alteração dos assets Inter disponíveis no
  workspace local; o build usa apenas as cópias versionadas neste diretório.
